# FramesAndNodes

The FramesAndNodes workbench is made to speed up your frame building workflow.
This is done by inserting and attaching frame members to geometry through a Task Panel.
After that it is easy to select multiple frame members in the 3D view and search and insert
a Node that was previously created.
